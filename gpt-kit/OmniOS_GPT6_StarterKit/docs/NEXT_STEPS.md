# Próximos pasos recomendados

1. Integrar el `MaterializationPortal` y dispararlo cuando el agente solicite crear una tarjeta.
2. Conectar `useServerHealth` a un endpoint real y mostrar `state`/`latencyMs` en la tarjeta de servidor.
3. Hacer que la IA seleccione IDs del `animationRegistry`, no que genere estilos libres en primera instancia.
4. Conectar `useCapabilities` a las capacidades reales del servidor y de Android.
5. Añadir registro de acciones: hora, acción, resultado y duración; nunca secretos.
6. Crear pruebas unitarias para validadores y pruebas de integración para adaptadores.
7. Añadir un sistema de importación/exportación de temas en JSON validado con un esquema versionado.
